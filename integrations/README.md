# Integrations

- [claude-code/](claude-code/README.md): a Claude Code skill
  (`codeeval-complexity`) and Stop hook template that run `codeeval check` and
  guide fixes. They are templates only; nothing is installed automatically.
- [git/](git/README.md): a `commit-msg` hook template that adds agent
  provenance trailers (`Agent`, `Agent-Harness`, `Agent-<Key>`) from the
  environment, for `codeeval attribution`.
